# Store assets

`screenshots/<lang>/65` (1242x2688, iPhone 6.5", the size App Store Connect accepted) and `screenshots/<lang>/69`
(1320x2868, 6.9") hold App Store screenshots of the current layout (4 tabs, build 12+), captured from the real running game by
`scripts/store-screenshots.cjs`. They are not mockups, but they were rendered by headless Chromium (software GL, web fonts),
so replace them with captures from a real device or the iOS Simulator before submission if you can.
Stats shown are from a boosted test save so fights last long enough to photograph. iPad 13" screenshots were not generated.
