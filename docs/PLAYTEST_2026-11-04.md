# Playtest, 2026-11-04 (5 agents)

Five agents played the dev build in headless Chromium (island, notch and SE screens; 8 languages) and reported on
visuals, gameplay and balance, first-time UX and localisation, bugs, and monetisation. Their raw notes are summarised
here with what was fixed in build 16 and what is still open.

## Fixed in build 16
**Bugs**
- Selling an equipped item paid coins and kept the item (infinite coins). Equipped items can now only be unequipped,
  `sellItem` only pays for bag items or the pending loot, and a stale item sheet closes itself.
- Import Save never worked: `pagehide` started a new session and saved over the import. `pagehide` now only saves,
  `gameManager.importSave()` blocks saving until the reload.
- A missing WebGL context on the loot card crashed the app, and the crash screen's button wiped the save. The 3D viewer
  falls back to the item icon; the crash screen is translated and only reloads.
- Malformed saves (null arrays, bad objects, negative coins) gave a permanent white screen. `sanitizeSave()` repairs
  them; if a save still cannot be applied it is backed up and the game starts fresh.
- Max HP changes (gym, gear, skills) restarted the current fight. Current HP is now scaled instead.
- Unequip with a full bag silently sold the item. It is now blocked with a message.
- The offline reward was lost on relaunch and did not grow while its card stayed open. It is saved and accumulates
  (still capped at 8 h).
- Day 6/7 daily rewards replaced a pending loot card; that item now goes to the bag. Pending skill replacements survive
  a relaunch. Unknown saved tabs fall back to Fighter. Reset now resyncs sound, haptics, graphics and reduced motion.
- Skill procs: Iron Chin halved the player's own damage, Shadow Slip and Vampiric Bite did nothing, Counter Striker
  fired on every hit. They now block, evade, heal and counter after a dodge as described.
- Gym gains produced HUD numbers like `5604.5999999999985`; final stats are rounded.

**App Review and ads**
- Removed the last gambling look-alikes: no dice icon or "roll"; "Another skill" only works on an open offer (first one
  free, then 25, 50, ... coins); "Free Gem Crate" is now "Free Gems"; mystery chest and wheel code is deleted.
- `PrivacyInfo.xcprivacy` no longer lists Google's ad domains as tracking domains (Apple blocks requests to listed
  tracking domains when the player declines ATT, which could have stopped ads for most players). Builds 16 and 17
  left `NSPrivacyTracking` true with an empty domain list, which Apple rejects (version went to Invalid Binary right
  after build 17 was submitted). Build 18 sets `NSPrivacyTracking` false like Google's own SDK manifest (13.11.0 has no
  tracking flag and no domains, and marks only the device ID as used for tracking).
- `public/app-ads.txt` added (needs to be live on https://streetfights.vercel.app/app-ads.txt, see below).
- Google consent (UMP) before ATT before AdMob init; "Privacy choices" in Settings when Google requires it.
- Full list of Google's 50 SKAdNetwork IDs; English-only ATT explanation; `maxAdContentRating` = PG.
- Ad loader: one retry per failure, no stale retry timer resetting a loaded ad, "no ad available" when an ad fails to
  show.
- Shop ads have daily caps (Free Gems 5, 2x Damage 6); Free Gems pays 3x the current stage reward in coins.
- The boss bonus offer keeps its 45 s while a loot or skill card covers it.

**Clarity and polish**
- Boss defeat: explains why, Retry is the main button (auto mode retries after 5 s), Gym button, ad revive secondary.
  The game no longer sits idle forever on that screen.
- Difficulty label uses expected time-to-kill on both sides (`src/core/combat.ts`) instead of power scores.
- One popup at a time: the daily card waits for the tutorial, the first win and the offline card, and closes after
  claiming. The Gym red dot needs 3x the cheapest upgrade.
- Quests view lists claimable rewards first.
- 2x speed unlocks after the first boss, 4x after world 2 (content no longer burns through in minutes).
- SUPER button only during a live fight; combat numbers are sharp on retina screens, larger and outlined.
- Minimum text size 10px; inventory header no longer wraps; reduce motion also stops CSS animations and confetti.
- Loot card uses the rarity colour, a larger model, no repeated rarity in the name.
- Localisation: profile strings in all 8 languages; stat labels, save import/export, combat callouts, deck messages,
  time formats, daily rewards; Turkish wording fixes (Süper Vuruş, Çanta, Can Çalma, Titreşim, Yetenek...); football
  leftovers renamed (energy orbs, Golden Glove King, opponent quotes).

## Phase 2, build 17
- **Balance** (docs/BALANCE.md): defence relative to the attacker, speed relative to the opponent, rarity-based
  percentage stats on items (save v5 normalises old ones), gym cost growth 1.22 + 1.5%/level on ATK and HP with MAX
  at caps, opponent growth 1.008 and softer bosses. Fights stay 6-10 s at every stage; losses ~15-25% on normal stages
  and 25-50% on bosses up to ~110, then a soft wall. Skill families have 2 skills each (set bonus upgrades at level
  6), forge keeps the best level, quest coins and offline income scale with progress.
- **Idle flow**: in auto mode duplicate skills level up and new skills join the deck with a toast (no modal); manual
  mode keeps the choice, runs at 1x and pays +25% coins.
- **Content in 8 languages**: skills, items, rarities, worlds, opponents, cosmetics, avatars and titles
  (`src/i18n/content.ts`); football leftovers renamed.
- **Rewarded ads** (fixed rewards, caps, cooldowns): double the daily login reward, one free gym level when short of
  coins (20 min cooldown, 6/day), a 2x damage card after a loss on a hard stage.
- **Visuals**: faces with expressions, no fighter clipping, arena signs clear of the HUD, living arenas, glowing epic+
  gloves, one headline callout at a time, stacked numbers, spark particles, lighter result overlay, bigger level-up,
  tutorial pointer ring, compact layout on small phones, fonts bundled.
